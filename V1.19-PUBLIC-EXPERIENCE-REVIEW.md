# CORE PRIME v1.19 — Public Experience Review

## Benchmark direction
- JLL: clear occupier value proposition, leasing workflow, curated availability, advisor connection.
- CBRE: strong data/analytics credibility, integrated occupier advisory, portfolio/lease intelligence.
- Cushman & Wakefield: straightforward search/filter structure and expert contact fallback.

## CORE PRIME positioning
CORE PRIME should not imitate a global brokerage corporate site. Its strongest position is:
1. verified Seoul office database,
2. comparison-ready availability,
3. enterprise shortlist/advisory.

## Implemented
- Premium editorial hero with database credibility and featured-building visual.
- Search moved into a prominent post-hero decision bar.
- Published-building / current-availability / verification metrics retained and visually clarified.
- Quick district shortcuts added.
- Decision framework rewritten around Search → Compare → Verify → Advise.
- Featured building cards redesigned with image-first hierarchy and freshness emphasis.
- Differentiation section added: verified data / comparable criteria / enterprise shortlist.
- Header simplified and primary advisory CTA added.
- Footer restructured around customer navigation and trust signals.
- ComparePicker rebuilt as a compact searchable selector rather than dozens of visible checkboxes.
- Buildings result toolbar made sticky; building cards receive refined interaction treatment.
- Advisory page redesigned as a professional briefing workflow.
- Accessibility and reduced-motion behavior retained.

## No database changes
No Supabase migration or SQL is required for v1.19.
