# CORE PRIME v1.19.1 — Public Experience Retest

## Review scope
Rechecked v1.19 customer-facing experience against current JLL/CBRE/Cushman office-leasing patterns and CORE PRIME's own data/advisory positioning.

## Fixes after retest
1. Public office search now paginates at 24 buildings per page instead of rendering the entire database at once.
2. Search/listing status logic is aligned with detail/compare pages and includes `contracting` consistently.
3. Homepage availability count is derived only from published, non-deleted buildings so hidden buildings do not inflate the public metric.
4. Hero verification badge now shows actual freshness status instead of always saying availability is verified.
5. Public footer no longer exposes the admin link.
6. Header label clarified from `이전 상담` to `기업 이전 상담`.
7. `/compare` is now useful when opened directly: users can select 2–4 published buildings there instead of hitting a dead-end instruction screen.
8. Compare selector gets a proper close label and empty-search feedback.
9. Building detail now displays exact total deposit / monthly rent / management fee values for total-amount CBRE leases when per-pyeong rates are not provided.
10. Homepage cards prefer road address where available.
